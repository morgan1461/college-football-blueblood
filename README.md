# College Football Blue Blood Dashboard

A React dashboard for college football fans featuring:

## Tabs

### Blue Bloods
View the eight historically elite college football programs with their national title counts and conference affiliations.

### Arbitrage Finder
Scan live sports betting odds from multiple bookmakers to detect arbitrage opportunities — situations where you can guarantee a profit by betting on all outcomes at different sportsbooks.

- Supports multiple sports (NCAAF, NFL, NBA, MLB, NHL, etc.)
- Uses [The Odds API](https://the-odds-api.com/) for live odds data
- Includes a sample data mode for testing without an API key
- Calculates optimal stake distribution and guaranteed ROI

## Getting Started

```bash
npm install
npm run dev
```

To use live odds data, get a free API key from [The Odds API](https://the-odds-api.com/) and enter it in the Arbitrage Finder tab.
